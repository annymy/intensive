# MyHashMap
Учебная реализация HashMap на Java. 

## Реализованные методы
- `put(K key, V value)` - добавление/обновление элемента.
- `get(K key)` - получение значения по ключу.
- `remove(K key)` - удаление элемента.
- `size()` - получение количества элементов.
- `clear()` - полная очистка коллекции.
- `containsKey(K key)` - проверка наличия ключа.
- `isEmpty()` - проверка на пустоту.

## Особенности реализации
- **Разрешение коллизий:** Метод цепочек (связные списки в каждой ячейке массива).
- **Динамическое расширение:** При достижении `loadFactor` (0.75) массив увеличивается в 2 раза, элементы перехешируются.
- **Защита от отрицательных индексов:** Используется битовая маска `(hash & 0x7FFFFFFF)`.
- **Обработка `null`:** Ключ `null` не допускается (выбрасывается `NullPointerException`).
- **Оптимизация хеша:** Применяется "размазывание" битов `h ^ (h >>> 16)` для равномерного распределения.
